# Task 2 — Heap Data Structure and Heapsort

Self-study implementation of the heap ADT (array-based and pointer-based) and heapsort, with benchmarking.

---

## How to Run

**Requirements:** Python 3.11 or later

```
pip install matplotlib numpy
```

```
python main.py
```

Runs the demo and benchmark. Four benchmark figures are saved to the project directory:
`bench_insert.png`, `bench_extract.png`, `bench_sort.png`, `bench_heapify.png`.

## Module Structure

```
task2/
├── heap_array.py        # Array-based max-heap
├── heap_pointer.py         # Pointer-based max-heap
├── heapsort.py   # Heapsort algorithm
├── benchmark.py        # `Performance benchmarking
└── main.py        # Entry point
```
